# Práticas com Asyncio em Python

Este repositório contém exercícios e práticas realizados durante o curso **"Praticando Python: programação assíncrona"** da Alura.

## 📚 Sobre o curso

O foco do curso é colocar em prática os conceitos de **programação assíncrona** usando a biblioteca `asyncio`, explorando:

- Criação e execução de corrotinas
- Uso de `async` / `await`
- `asyncio.run`, `create_task` e `gather`
- Concorrência com múltiplas tarefas assíncronas

## 🧪 Conteúdo do repositório

Cada arquivo representa uma prática individual proposta no curso. Exemplos de conteúdos abordados:

- Execução assíncrona de funções
- Delays simulados com `asyncio.sleep`
- Execução paralela com `asyncio.gather`
- Diferença entre chamadas síncronas e assíncronas
